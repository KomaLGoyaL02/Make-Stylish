# Make Stylish — Professional Footwear Store 

A clean, premium and simple-to-use responsive frontend for a footwear e-commerce store.

Open `index.html` in any modern browser.

Highlights:
- Minimal premium visual design
- Clear navigation and simpler shopping flow
- Men / Women / Kids browsing
- Expanded footwear catalog and product filters
- Product detail, sizes and quantity
- Cart, wishlist, checkout and order demo
- Responsive desktop/tablet/mobile layout
- Frontend-only demo; connect a backend/database and payment gateway for production
